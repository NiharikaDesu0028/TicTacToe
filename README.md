# 🎮 Tic Tac Toe

A simple, browser-based **Tic Tac Toe** game built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

---

## 📖 Project Description

This is a two-player Tic Tac Toe game that runs entirely in the browser. Players take turns marking cells on a 3×3 grid as either **X** or **O**. The game automatically detects wins across all rows, columns, and diagonals, handles draw conditions, and allows players to restart at any time.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **HTML5** | Game structure and layout |
| **CSS3** | Styling, grid layout, and hover effects |
| **JavaScript (Vanilla)** | Game logic, event handling, win/draw detection |

> No build tools, package managers, or external libraries required.

## 🚀 Setup & Installation

Since this is a plain static web app, there's no installation needed.

1. **Clone the repository**
   ```bash
   git clone https://github.com/NiharikaDesu0028/TicTacToe.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd TicTacToe
   ```

3. **Open the game in your browser**
   - Simply open `index.html` in any modern web browser, or
   - Use a local server (e.g., VS Code's **Live Server** extension) for a better development experience.

---

## 🕹️ Usage

1. Open `index.html` in your browser.
2. **Player X** always goes first.
3. Click any empty cell to place your mark.
4. The status bar updates to show whose turn it is.
5. The game announces the **winner** or a **draw** when the board is complete.
6. Click **Restart Game** to reset the board and play again.

- ✅ One-click game restart

- ✅ Zero dependencies — works offline out of the box
